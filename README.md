## 3. Анализ отношений

### 3.1. Тип отношений

**Созависимые отношения с элементами эмоционального насилия.**

- **i** использует суицидальные темы как манипуляцию (осознанно или нет).

- Оба застревают в паттерне «жертва-спасатель».
- Отношения не здоровые, но оба слишком привязаны, чтобы разорвать их.

### 3.2. Паттерн конфликта

1. **i** чувствует вину → говорит «прости», «я плохой», «лучше мне умереть».
2. **Женечка** пугается → успокаивает, убеждает, что он хороший.
3. **i** временно успокаивается → говорит «я останусь», «я не умру».
4. Через некоторое время цикл повторяется.

### 3.3. Эмоциональная динамика

- **i** — эмоциональный «качун». Его настроение определяет настроение Женечки.
- **Женечка** — эмоциональный «якорь». Она стабилизирует «i», но ценой собственного психического здоровья.
- Оба страдают, но не могут друг без друга.

### 3.4. Рекомендации

**Для «i»:**
- Обратиться к психотерапевту (КПТ, схема-терапия).
- Научиться выражать эмоции без самобичевания.

- Развить навыки эмоциональной саморегуляции.

**Для Женечки:**
- Установить границы. Нельзя спасать человека, который не хочет спасаться.
- Обратиться к психотерапевту (созависимые отношения).
- Перестать чувствовать ответственность за чужую жизнь.
- Научиться говорить «нет».

**Для обоих:**
- Отношения нуждаются в профессиональной помощи.
- Возможно, стоит временно разойтись, чтобы оба могли поработать над собой.
